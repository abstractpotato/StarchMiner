# StarchMiner

## Commands:
```
help -> help commands
h -> help commands
-------------------------------------------------------------------
# can use 's' instead of start
start <companies or miners> -> starts miners and companies
start <*.json>              -> starts from config file
-------------------------------------------------------------------
# can use 'm' instead of miner
miner mine <miner_ids>  -> mine with these ids
miner <miner_id>        -> print miner miner snapshot
-------------------------------------------------------------------
# can use 'c' instead of company
company mine <company_ids> -> mine all members of these companies
-------------------------------------------------------------------
# can use 'mt' instead of start
monitor -> view the blockchain
```

## Requirements:
- Python 3.8 or later : https://www.python.org/downloads/
- Requests Module: https://pypi.org/project/requests/
